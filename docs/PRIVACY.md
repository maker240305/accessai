# 데이터 처리

- AccessAI는 원본 웹사이트 서버를 수정하지 않습니다.
- 사이트 동작은 사용자의 브라우저에서 발생합니다. 버튼 클릭과 폼 제출은 원본 사이트에 실제 영향을 줄 수 있습니다.
- AI를 사용하려면 최초 전송 동의가 필요합니다. 페이지 전체 HTML 대신 필요한 텍스트와 요소 정보, 분석할 이미지가 Google Gemini API로 전송됩니다.
- 비밀번호·카드 자동완성·OTP 입력란은 탐색 목록에서 제외하고 입력값은 AI로 보내지 않습니다. 주변 문맥에 개인정보가 포함될 수 있으므로 민감한 사이트에서 AI 분석을 사용하지 마세요.
- 무료 Gemini 입력은 Google 제품 개선에 사용될 수 있습니다. https://ai.google.dev/gemini-api/terms
- 음성 인식은 Chrome의 제공 서비스에서 처리될 수 있습니다. AccessAI 프록시에 원본 음성을 보내지 않습니다.
- 이미지 설명 캐시는 `chrome.storage.local`에 내용 해시 기반으로 최대 200개, 유효기간 30일로 저장합니다. 이미지 원본은 캐시하지 않습니다.
- 설정과 캐시는 확장 삭제 시 제거됩니다. 로그인·사용자 DB·추적 분석 도구를 사용하지 않습니다.

- 사진은 기존 alt를 답변으로 사용하지 않고 이미지 픽셀을 분석합니다. 원본 가져오기가 막힌 경우 활성 탭 화면을 로컬에서 캡처한 뒤 해당 사진 영역만 잘라 전송합니다. 전체 화면은 서버에 전송하거나 저장하지 않습니다. 화면 밖 부분은 이 경로에서 분석되지 않습니다.
